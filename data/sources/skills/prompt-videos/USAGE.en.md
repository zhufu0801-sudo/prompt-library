# Video action and camera prompts

Instruction-only adaptation. Specify single-shot action, start/end state and camera movement. Extract the folder into a tool supporting SKILL.md, or paste the document and generated prompt into chat. Request English output. No model, API key or installer is included. Editing files, running code and generating media require tools in the target AI; without them return content and steps without claiming execution.
