# Image edit and preservation brief

Confirm original image availability, desired edit region, target software, intended use and non-negotiable details. Do not claim an image is uploaded unless accessible.
Create two lists: change and preserve. Clarify conflicts, such as changing a pose while demanding pixel-identical anatomy. Ask only essential unresolved questions.
Describe the desired final appearance of the region, perspective, light direction, edge blending and contact shadows. For text, quote exact characters and discuss manual typesetting when precision is required.
Deliver one concise edit prompt, a separate masking/reference checklist and acceptance checks for the protected subject, logo, proportions and untouched regions. Provide a targeted follow-up correction for a failed attempt rather than restarting every instruction.
Do not invent recovered details or promise pixel identity. If you cannot view images, label the acceptance list as a manual comparison plan. No image-generation engine is bundled.
