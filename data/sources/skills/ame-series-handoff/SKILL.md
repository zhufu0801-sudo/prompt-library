# Series project handoff

Ask for the last approved frame description, character/costume sheet, episode objective, target software and available references. If already supplied, do not ask again.
Separate immutable canon from episode-specific changes. Assign episode/scene/shot IDs. For each shot write duration preference, framing, subject action, camera motion, start state, end state, reference assets and invariants.
When revising, preserve approved shots and record before/after, reason and affected downstream shots. Suggest changes to downstream shots for confirmation rather than silently rewriting them.
Deliver: episode outline, shot table, one copyable production prompt per shot, reference checklist, handoff notes and unresolved continuity checks. Keep software settings separate from prompt text. Without actual visual inspection, describe continuity checks as textual/manual; never certify facial identity from descriptions alone.
Acceptance: adjacent end/start states connect; props and costumes persist unless an intentional change is recorded; every reference can be identified; no invented source images or model feature claims.
