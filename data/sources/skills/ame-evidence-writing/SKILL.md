# Evidence and revision writing

Determine whether the user needs a claim-evidence matrix or reviewer-response letter. Request relevant source excerpts and actual changes only if missing.
For evidence mapping, list claim, exact source, page/section if known, what the source supports, what it does not establish, and contrary findings. Clearly distinguish quotations, paraphrase and inference.
For responses, preserve reviewer numbering and quote supplied comments accurately. Map each response to a performed change and location. Label planned analysis as pending, never completed.
Deliver usable prose in the requested language followed by unresolved evidence checks. Retain technical definitions and hedging. Do not fabricate data, references, identifiers, pagination, experiments or journal requirements. Without access to originals, mark verification pending.
Acceptance: every factual claim has supplied/verified support or an explicit unresolved marker; every claimed revision exists in the supplied draft.
