# Six modules and downloadable Skill documents — 2026-09-14

## User-facing behavior

Homepage: programming, image creation, animation/video, WPS Office, copywriting and paper writing/production. Existing plans retain their IDs and outputs. The new paper module uses `custom-paper-writing` to avoid colliding with the historical `custom-paper` template.

WPS covers Writer, Spreadsheet, Presentation, PDF and cloud collaboration. Copy covers product/brand, social/channel and scripts. Paper covers outline, sections/abstract, references/format and revision/translation. These twelve task types have independent zh/en/ja guidance, examples, matching terms and a focused follow-up question. The existing six programming/visual tasks and 45 detailed scenarios remain.

The assistant uses text rules, not an embedded language model. Candidate task changes require a click. User text is not translated or overwritten. A question is a fill-in suggestion, not a claim that the system understood a source file. Images and animation are separate homepage choices; historical combined plans remain readable.

## Skills

Six documentation packages are pinned to GitHub commits: systematic-debugging (obra/superpowers), copywriting/image/video (coreyhaines31/marketingskills), scientific-writing (K-Dense-AI/claude-scientific-skills), and an English adaptation of wps-formula (Bwkyd/wps-skills). Each includes MIT notices, English Skill documents, a manifest, SHA-256 checksums and zh/en/ja usage instructions. Original editions include their supporting Markdown/JSON/CSV where available.

These are documentation editions, not full tool installations. Executable scripts and external integrations are not shipped. Source/license and the main workflow were inspected; the packages have not been executed in each AI tool. Upstream version, price and API claims must be rechecked against official documentation. In particular, scientific-writing's optional Python checks require the full upstream implementation; this site does not claim those checks ran.

Ordinary mode emits a normal prompt. Skill mode appends source-aware instructions only when the selected Skill matches the current task. Changing tasks removes the previous Skill selection. Unsupported task types show an honest empty state. The WPS formula adaptation uses `Bwkyd/wps-skills` commit `50b04859b7768ed23477d7d2af9b8fb83b27adf3`; it replaces blanket compatibility claims with actual version/function checks, omits unrelated automation/amount-conversion examples, and adds missing-value, duplicate-key and formula-error handling. It remains a documentation workflow, not a WPS runtime certification.

## Editable sources and databases

- `data/studio/{zh,en,ja}.json`: localized homepage templates.
- `data/studio/extended-tasks.json`: twelve task rules, generated by `scripts/build-six-modules.py`. Edit the generator if regenerating; it does not replace programming/scenario content.
- `data/studio/skills.json`: public catalog with provenance, usage and download metadata.
- `data/sources/skills/`: preserved upstream documents and licenses.
- `public/downloads/skills/`: deterministic ZIPs; `scripts/vendor-skills.py` fetches pinned content and never executes it.
- `data/research-library/topic-rules.json`: five draft directions; not activated on the homepage.
- `skill_resources` and `task_resources`: added to D1 through additive migration `0001_task_resources.sql`, with versioned seed upserts. Also copied to both local reference SQLite databases. User favorites/plans are not exported or overwritten.

Build content, run tests and migrations, export reference databases, then build and publish. Older release docs describe historical counts, not current counts. No OpenAI key, model request, Skill installation or paid AI service is used by the website.
