# Matching refinement

Rule-based matching now normalizes Unicode, checks ASCII token boundaries, suppresses a limited set of explicit exclusions, lowers standalone generic terms, and recognizes curated everyday phrases across Chinese, English and Japanese. Only the top scene within the selected task is automatically included, avoiding conflicting prompt packs. Manual scenario selection still takes precedence. Related scene evidence can suggest switching task; switching remains a user action.

Coverage includes login redirects, duplicate rows, install/type/null/layout failures, async races, character appearance, scene continuity and close/medium/wide framing. Source: original editorial aliases, not a trained model. Negation handling is deliberately narrow and is not semantic understanding. Ambiguous multi-intent requests may require manual scene selection. No model API or new data transmission is introduced.

Follow-up when usage allows: expand multilingual realistic-query evaluation and introduce user-selectable alternative scene suggestions. Avoid claiming confidence percentages for heuristic scores.
