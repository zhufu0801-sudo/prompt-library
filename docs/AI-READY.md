# 下一阶段 AI 接入准备

当前所有生成均来自数据库模板和规则。`lib/ai/provider.ts` 定义推荐、优化、运行的接口，禁用实现明确报错。`GET /api/ai` 返回关闭状态，`POST /api/ai` 返回 501，任何 UI 点击均不触发模型请求。

真正接入时再实施：

1. 增加服务端 provider SDK 与密钥 secret；不在浏览器或 GitHub 存放密钥。
2. 为用户增加正式身份、服务端配额、输入长度、输出预算和请求频率限制。
3. 推荐只返回经过 schema 验证的字段词条；锁定字段不可被模型覆盖。
4. 只在用户明确点击时调用，不随输入框每次变化自动调用。
5. 请求只包含所选模板和必要字段；私有方案不进入共享缓存。
6. 记录调用次数和成本摘要，错误或无额度时基础模式仍可工作。
7. 再单独设计 provider 配置和模型选择，不把模型写死到模板数据。

此文档是后续实施边界，不代表当前已存在配额、计费或 AI 功能。
