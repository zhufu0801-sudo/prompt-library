# AI Made Easy interface direction

Use a quiet blue and lavender studio palette, generous whitespace and a clear distinction between guided templates and the complete source library. Main task: choose a topic, describe a need, copy a usable prompt. Keep the language control visible.

Design tokens: background #fcfcff, ink #18243d, muted #5b657a, accent #3454d1, tint #edf3fc, secondary #f1e4ef. Body type uses the device system stack; a local serif stack gives the main title a softer character without external font downloads. Cards have restrained borders and no heavy shadows. Ten category controls filter compact template cards; complete source records use rows.

Follow the reviewed Anthropic frontend-design Skill at commit 34040c9c568585f6929bedeaad110ad08f079624 (Apache-2.0). Remove decorative numbering and repeated tag clutter. Keep error, empty, loading, focus, reduced-motion and mobile states. Preserve native form labels and download semantics.
