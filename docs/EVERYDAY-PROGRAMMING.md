# Everyday programming batch

12 original scenarios with Chinese, English and Japanese instructions/examples. These are editorial additions for the user's common-programming request, not newly imported or purportedly executed GitHub code.

- Build: field validation, CRUD, keyword search, downloads/CSV.
- Debug: installation conflicts, type mismatches, null values, expired login, duplicate lists, mobile overflow.
- Review: performance, configuration/secrets.

Existing date/timezone, async race, pagination and authorization scenes are retained rather than duplicated. Each new scene specifies evidence to collect, concrete deliverables and relevant checks. Scope remains two homepage modules; new scenes appear under their own task type. Prompt generation remains rule-based, with optional scene rules and no model API.

Maintain scripts/curate-everyday.py and regenerate data/studio/everyday-scenarios.json. Synchronize selector labels with scripts/sync-spatial-scenarios.mjs, then export the catalog. Current totals: 45 published scenes + 8 drafts = 53 scenarios, 159 localizations. Source inventory counts are separate from these reviewed scenarios.
