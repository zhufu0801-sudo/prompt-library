# 2026-09-15：关怀版与任务扩展

当前共 57 个模块、225 个可填写任务模板、366 条完整库记录，以及 8 个 GitHub 来源的 Skill 文档包。任务、界面和关怀版支持中文、英文、日文。本轮新增 60 个原创任务；不是新增 60 条上游导入内容。

## 具体任务

覆盖安全、性能、移动开发、自动化、Git、接口集成、游戏、后端、测试、运维、照片、角色、剪辑、3D 资产、视频制作、WPS、论文制作、文案、数据分析和学习。每项具有独立的目标、资料问题、交付要求与验收约束，例如日志脱敏、慢查询定位、老照片修复、角色服装一致性、循环视频接缝、WPS 公式报错、论文局限性、图表说明和回复审稿意见。

## 关怀版

独立的三步流程：用一两句话说需求；核对并选择目标、补充信息与回答长度；复制整理后的提示词给用户自己的 AI，也可下载 TXT。

本地规则提供 12 个方向（含其他需求），处理常见中英日关键词、部分否定语句、多意图和未知需求。不会自动替用户确认目的。整理结果保留原始文字；没有根据年龄猜测经历或身体情况。没有接入或训练大模型，不能保证理解任意复杂自然语言；未知需求由用户选择方向，原话仍交给后续 AI 理解。

关怀版输入仅保存在当前页面组件状态，不上传、不写入浏览器持久存储。浏览器只记住语言和版本偏好。退出关怀版会清空该流程。网站本地整理不产生模型 API 费用；外部 AI 的收费由其服务决定。

大字、56px 以上操作按钮、明确的错误提示与步骤焦点；关怀版取消动画。普通版重做分类侧栏、两列任务卡、逐批加载与流程导航，增加短暂的点击、展开和通知动画，尊重系统减少动态效果设置。

- [Prompts.chat](https://github.com/f/prompts.chat)：已有固定版本来源库继续保留来源与审核状态；未审核内容不会冒充已验证模板。

固定上游版本、许可证与文件校验值保留在 Skill 数据中。新增独立下载入口展示全部 8 个文档包、适用范围、使用方法、主下载和 GitHub 备用下载。下载的是文档包，不包含大模型，也不代表已经在每个第三方 AI 中完成运行认证。

推荐同时检查目标任务、需求正文、限制、已有资料、验收要求和关键词。WPS 公式 Skill 不用于透视表需求；图片营销 Skill 不推荐给老照片修复；九宫格空间一致性需求不套用普通图像营销流程。新增任务仅在原 Skill 能力范围内扩展映射。图片和动画默认关键词分别维护。
